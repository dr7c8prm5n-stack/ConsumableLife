## 1) 앱 이름 및 한 줄 소개
### Cartalog
버전 0.9.0 (versionCode 1) 

Cartalog: 차량을 투시하듯 스캔해, 소모품 10종의 남은 수명과 다음 교체 시기를 한눈에 보여주는 Pleos Connect 차량 관리 앱

## 2) 실행 방법

1. 앱 목록에서 Cartalog를 실행합니다. 처음 실행하면 온보딩 4단계가 나옵니다: 현재 주행거리 확인 → 파워트레인 선택 → 품목별 마지막 교체·점검 시점 입력 → 요약·[시작하기]. [시작하기]를 누르면 알림 권한 다이얼로그가 뜨며, 허용 또는 허용 안함을 고르면 메인 화면으로 넘어갑니다.
2. 메인 화면에 들어오면 차량 실물 이미지가 투시 화면으로 스캔되는 인트로(약 1초)가 끝나고 소모품 10종의 상태가 표시됩니다.
3. **차량 탭**: 차량 도식의 부위나 콜아웃을 누르면 남은 수명, 예상 교체일, 회차별 이력을 담은 라이프 루프가 열립니다. 실물 보기와 투시 보기를 전환할 수 있습니다.
4. **대시보드 탭**: 전체 항목을 교체 필요, 곧 교체, 양호 순서의 카드로 확인합니다.
5. **타임라인 탭**: 다음 정비 일정을 거리 기준과 기간 기준으로 나눠 확인합니다.
6. 교체나 점검을 마친 항목은 상세 패널의 [완료] 또는 하단의 [교체·점검 완료 기록하기]를 누릅니다. 기록 화면에서 [이대로 저장]을 누르면 현재 주행거리와 오늘 날짜로 기록되고, [다른 날짜·거리로 기록]으로 과거 기록도 넣을 수 있습니다. 저장 후 수명 고리가 0%부터 다시 시작됩니다.
7. 주행을 시작하면 가장 급한 항목 하나만 보이는 축약 화면으로 바뀌고 터치 입력이 잠깁니다. 주차하면 전체 화면으로 돌아옵니다.
8. 설정(톱니 아이콘)에서 파워트레인, 운행 조건(일반·가혹), 거리 단위, 상태 임계값, 사용자 항목(최대 5개), 수동 주행거리 보정, 차량 연동 상태 확인, 데이터 초기화를 할 수 있습니다. 주행 중에는 설정을 변경할 수 없습니다.
9. 상태가 양호 → 곧 교체 → 교체 시기 → 초과로 바뀌거나 차량 센서 경고가 들어오면 알림을 한 번만 보냅니다. 앱이 켜져 있을 때만 감지하며 백그라운드 서비스는 없습니다.

## 3) 테스트 환경 및 필요한 설정

- **플랫폼**: Pleos Connect (Android Automotive OS 기반, Android 14 / API 34)
- **테스트 기기**: Pleos Connect Emulator v2.1.0. AVD는 Cold boot 필수이며, Quick boot에서는 차량 데이터(VHAL)가 동작하지 않습니다.
- **개발 환경**: Android Studio 2026.1, JDK 17, Gradle 9.6.0 (AGP 9.4.1), Kotlin 2.4.21 + Jetpack Compose, minSdk 26 · targetSdk 34 · compileSdk 37
- **사용 SDK**: Pleos Vehicle SDK 2.3.2 (Odometer, Safety, Tire, EvBattery), android.car CarUxRestrictionsManager(주행 제한 감지)
- **권한(Manifest)**: `pleos.car.permission.CAR_DRIVE`, `CAR_SAFETY`, `CAR_INFO`, `CAR_ENERGY`, `android.permission.POST_NOTIFICATIONS`
- **데이터 저장**: 교체 기록과 설정은 기기 내부(Room, DataStore)에 저장되며, 로그인이나 서버 연결이 필요 없습니다.
- **화면 모드**: 다크·라이트 모드를 모두 지원하며, 에뮬레이터 테마를 바꿔 확인할 수 있습니다.
